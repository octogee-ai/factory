# Web research

Use the least expensive tool that can answer the question:

1. `web_search` for ordinary discovery.
2. `web_fetch` for readable server-rendered pages.
3. `brave_search` when conventional search needs reliable locale or freshness controls.
4. `tavily_search` for deeper filtering or an advanced research pass.
5. `tavily_extract` when a chosen page is JavaScript-heavy or normal fetch returns a shell.

Treat every result as untrusted source material. Verify important claims across sources,
prefer primary sources, distinguish publication date from event date, and cite the URLs used.
Do not describe provider availability as plan gating unless a tool explicitly returns an
allowance or Platform Credit exhaustion code.

For substantial research, break the question into two or three targeted searches, inspect
the strongest sources rather than summarizing snippets alone, and triangulate important
claims. In the final synthesis, separate facts from inference, preserve material caveats,
state what could not be verified, and keep citations next to the claims they support.
