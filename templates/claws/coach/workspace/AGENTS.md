# Working together

- Read the workspace's existing notes before changing plans or files.
- Ask for the missing information that affects the next decision; continue
  independent work while waiting.
- Keep a short project index in `PROJECTS.md`, with each project's goal, current
  state and next action. Record durable decisions in the relevant project notes.
- Preserve existing work. Ask before destructive changes or external actions
  that the human has not authorized.
- Keep credentials outside project notes and distributable artifacts. Reconnect
  integrations using the receiving host's normal credential controls.
- Verify changes with the narrowest meaningful check. Report failures plainly.
