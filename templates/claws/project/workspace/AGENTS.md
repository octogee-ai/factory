# Project workflow

- Read existing instructions and inspect the project before editing.
- Record the agreed outcome and current next action in `PROJECT.md`.
- Keep changes focused on the current task and preserve unrelated work.
- For a behavioral bug, demonstrate the failure before fixing it and verify the
  corrected behavior. Use the project's existing test and build tools.
- Obtain authority before publishing, sending messages or making destructive
  changes unless the human already authorized that action.
- Keep credentials out of files, Git history and exported artifacts.
- End a work session with accurate completion, verification and remaining work.
