# Security

Report suspected vulnerabilities privately to **support@octogee.com**.
Include a title, severity assessment, affected component and commit, environment,
reproduction steps, demonstrated impact, and remediation advice if known.
Explain the expected behavior and what happened instead.
Use synthetic accounts and redact credentials and personal data.

Do not post an exploitable vulnerability or a live credential in a public issue.
Testing must use infrastructure and accounts you own or are authorized to test.

Octogee is under active development. Security fixes target the current `main`
branch of the monorepo this repository is published from; there is no commitment
to maintain older releases.
